Mania Preview

Roxysu Preview is a standalone mania notefield overlay for Tosu. It follows the map you’re playing in osu! — no Roxysu app install required.

Download RoxysuPreview How to install

What it is

A live mania preview, served by Tosu

The counter talks only to Tosu: it reads the live map and paints a mania playfield — receptors, notes, lane cover, and your imported skin. Use it in the Tosu dashboard or as an OBS browser source at /RoxysuPreview/.

Osu!mania only

Only the osu!mania game mode is supported. Other game modes are not currently supported.

Live clock

Scrolls with in-game time, including Invert, Hold Off, and Mirror.

OBS-ready

Transparent background, playfield scale, and hide-while-playing for browser sources.

Your skin

Drop a .osk next to the counter and name it in the Tosu dashboard settings.

Install

Same as any other Tosu counter

Tosu loads counters from its static folder. Roxysu Preview is just another folder you drop in there.

Setup

Put RoxysuPreview in Tosu’s static folder

  1. Download RoxysuPreview.zip from the v0.1.14 release.
  2. Unzip it. You should have a folder named RoxysuPreview.
  3. Copy that folder into Tosu’s static directory — the same place every other Tosu counter lives.
  4. Open the Tosu dashboard. Roxysu Preview appears as a counter you can enable, with its own Settings button.

After install, the overlay URL is /RoxysuPreview/ (512×720). Point an OBS browser source at it if you want it on stream.

Settings

Tune the notefield from the Tosu dashboard

Open RoxysuPreview → Settings. Values save in Tosu and apply live. You can also use the gear on the preview itself as a fallback.

Scroll speed

osu!mania scroll speed, from 1 to 40.

Hit position (%)

Receptor line as a percent of playfield height (55–95).

Lane cover (%)

Black cover from the top of the playfield (0–70).

Playfield size (%)

Notefield size relative to the overlay (20–100).

Transparent background

Clear the page background so OBS can key the overlay.

Roxysu watermark

Draw the Roxysu logo and wordmark on the notefield.

Song-select preview

Keep the playfield visible in song select when no map is loaded.

Hide while playing

Fully hide the overlay during gameplay. Enable transparent background on the OBS browser source too.

Skin

Import a .osk into the overlay

Tosu’s dashboard has no file picker, so the skin file has to sit next to the counter. Then you type the filename in settings.

  1. Place the .osk inside Tosu’s static/RoxysuPreview/ folder — the same folder you copied in during install.
  2. In the Tosu Dashboard, open RoxysuPreview → Settings → Skin.
  3. Put the filename in Import .osk — for example myskin.osk or ./myskin.osk.
  4. Click Update settings.

To remove a skin, turn on Reset imported skin, save, then turn it off again. You can also drop an .osk onto the preview itself when you’re not in OBS.
